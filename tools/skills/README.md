# 전역 스킬 복원

`manifest.json`이 설치 목록의 정본입니다. 사용자 설치 스킬 18개의 원본 스냅샷·파일별 SHA-256, CLI 패키지 2개의 고정 버전, 앱 관리 플러그인 13개를 기록합니다. 경로는 현재 PC의 CODEX_HOME·사용자 홈에서 계산합니다.

- `Restore-Skills.ps1 -CheckOnly`: 현재 설치·차이를 확인합니다.
- `Restore-Skills.ps1`: 누락된 스킬과 CLI만 설치합니다. 다른 내용의 기존 파일·버전은 보존하고 차이를 보고합니다. uv가 없으면 Windows winget으로 설치합니다.
- `Export-Skills.ps1`: 설치 스킬을 원본 그대로 기록합니다. 다른 PC에 없는 기존 등록 항목은 삭제하지 않습니다. 재등록 전 비밀정보·개인 데이터를 검토합니다.
- `Sync.ps1 -Direction Pull`: 지침 동기화 후 복원을 실행합니다. 지침만 받으려면 `-SkipSkills`를 지정합니다.
- `Sync.ps1 -Direction Push`: 지침과 스킬 목록·스냅샷을 갱신합니다. 업데이트 기록·개별 결과 보고서는 전역 규칙에 따라 같은 작업에서 별도로 등록합니다.

공식 `.system`과 플러그인 캐시는 복사하지 않습니다. 앱 버전과 플러그인 설치·계정 연결은 Codex와 Plugin Management에서 확인합니다. 캐시 존재를 연결 성공으로 보지 않습니다. 인증정보와 세션은 동기화하지 않습니다.

기존 스킬이 다르면 자동 덮어쓰기하지 않습니다. 차이를 검토해 사용자 변경을 보존·병합하고 승인된 정본을 다시 기록합니다. 새 PC에서 스킬을 복원한 후 새 대화에서 발견되는지 확인합니다.
