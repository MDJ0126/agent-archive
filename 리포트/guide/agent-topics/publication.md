# 보고와 게시

- 단순 대화·짧은 질의응답과 영향이 작은 오탈자·문구·간격 조정은 채팅으로 마무리합니다. 주요 기능 변경·버그 수정·운영 지침 변경과 사용자가 등록을 요청한 작업은 중앙 보고 대상으로 삼습니다.
- 보고 대상 작업은 JSON v2와 필요한 실제 증거를 작성하고 프로젝트 예외를 확인합니다. 최종 답변 전에 중앙 아카이브에 커밋·푸시해 배포를 시작하고, Pages 게시 완료와 공개 접근 확인은 기다리지 않습니다. 미확인 상태는 구분해 표시합니다. 웹 변경은 해당 프로젝트 성능 기준과 게시 체크를 확인합니다.
- 새 보고서를 등록할 때 같은 프로젝트의 중앙 보고 대상인 완료·부분 완료 작업을 중앙 등록·게시 목록과 대조합니다. 이전 작업·세션에서 제출에 실패했거나 빠진 보고서 중 근거와 공개 범위가 확인된 건을 작업별로 작성해 이번 제출에 함께 올립니다. 이미 등록된 건의 게시 지연은 배포 상태로 구분합니다.
- SNS 글은 승인본의 문체와 공개 범위를 문서에서 확인합니다.
