# 전역 설정과 동기화

- 설치본과 중앙본의 차이를 확인하며 최신 원격 규칙과 미완성 로컬 변경을 보존합니다. 변동된 지침·업데이트 항목·결과 보고를 함께 기록하고 설치본과 중앙본의 해시를 확인합니다.
- 스킬·CLI 선택과 평가 시점은 도구 선택 절에서, 설치 경로·해시·복원은 다른 PC 복원 절에서 확인합니다. 다른 PC의 반영과 새 세션 검증은 각각 확인할 때만 완료로 기록합니다.
