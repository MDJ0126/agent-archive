# 작업별 지침

대상 프로젝트의 지침과 변경에 필요한 원문을 먼저 확인합니다. 작은 변경은 필요한 확인만 수행하고, 별도 실행 계획이 필요한 작업은 완료 기준과 검수 방법을 먼저 적습니다.

## Unity 작업

샘플 프로젝트의 [네이밍 규칙](네이밍%20규칙.md)과 [코드 스타일](코드%20스타일.md)을 관련 변경의 참고 자료로 사용합니다. 다른 프로젝트에 적용할 때는 해당 프로젝트의 규칙과 기존 코드를 먼저 확인합니다.

## 도구와 산출물

엔진별 검증, 외부 도구, 디자인, 대용량 파일, 저장·종료 절차는 [전체 작업별 지침](../work-instructions.md)에서 해당 절을 확인합니다.
