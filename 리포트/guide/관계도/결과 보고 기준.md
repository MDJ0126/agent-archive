# 결과 보고 기준

보고서 첫 부분에서 실제 결과와 남은 일을 설명합니다. 구현·빌드·실행·푸시·배포 상태는 각각 기록합니다.

- 결과는 [결과 보고서 양식](../template-report.md), 버그는 [버그 보고서 양식](../template-bug.md)을 참고하고, 실제 등록은 [공통 JSON 작성 가이드](../index.html)를 따릅니다.
- 보고할 증거의 형식과 작업별 공개 범위는 [검수 증거](검수%20증거.md)와 관계도의 **보고·공개 예외**에서 확인합니다.
- 중앙 아카이브 게시 확인이 남았다면 현재 확인된 단계까지 표시합니다. 게시 보류·비공개 요청은 해당 범위에 적용합니다.
