# 품질 점검 절차

1. **착수** — 대상 버전·실행 환경·완료 기준과 필요한 검수 범위를 정합니다.
2. **실행** — 현재 버전에서 기대 결과와 실제 결과를 비교하고 [검수 기록](검수%20기록.md)을 남깁니다.
3. **실패 처리** — 실패·차단 결과를 보존하고 원인을 확인한 뒤, 수정한 버전의 새 결과를 기록합니다.
4. **종료** — 실제 확인한 범위를 적고 미실행·차단·미확인 항목을 다음 작업으로 넘깁니다.

작업 메뉴얼이 필요한 경우에는 전체 미완료 목록을 보존하고, 후속 회차에서 1~5개씩 실행합니다. 메뉴얼을 완료로 등록할 때에는 현재 버전의 전체 최종 QA와 근거를 확인합니다.
