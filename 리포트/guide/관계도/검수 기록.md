# 검수 기록

검수 대상마다 기대 결과와 실제 관찰을 나란히 남깁니다. 수정 전 실패와 수정 후 검수는 별도 행으로 기록합니다.

| 항목 | 기록할 내용 |
| --- | --- |
| 대상 | 기능·파일·환경·버전과 확인한 시각 |
| 절차 | 같은 조건으로 다시 확인할 수 있는 최소 단계 |
| 기대 / 관찰 | 기대 결과와 실행에서 확인한 실제 결과 |
| 판정 | 통과·실패·차단·미실행 중 해당 상태 |
| 근거 / 후속 | 로그·캡처·명령 결과 또는 차단 이유와 남은 확인 |

Unity 샘플의 씬 초기화처럼 진입점이 여러 개인 변경은 [씬 직접 실행과 실제 씬 전환](../../projects/sampleprojectforunity/guidelines.html)을 구분합니다. 재실행은 영향받는 범위에서 수행합니다.
