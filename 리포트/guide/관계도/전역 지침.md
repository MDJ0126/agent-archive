# 전역 지침

모든 작업에서 적용하는 기본 기준입니다. 실제 절차는 아래 문서에서 찾아보세요.

| 필요한 기준 | 문서 |
| --- | --- |
| 작업 범위 결정, 프로젝트 원문, 샘플 참조 | [작업별 지침](작업별%20지침.md) |
| 실행 전 준비, 검수 결과와 실패 처리 | [품질 점검 절차](품질%20점검%20절차.md) |
| 결과 보고, 증거, 공개 상태 | [결과 보고 기준](결과%20보고%20기준.md) |
| 프로젝트별 규칙과 근거 | [전용 지침 목록](../project-instructions.html) |
| 프로젝트별 보고·공개 예외 | [보고 예외 프로젝트](보고%20예외%20프로젝트.md) |

지침 적용 대상과 최신 사용자 요청을 먼저 확인합니다. 실제로 관찰한 결과와 미확인 항목을 구분하고 기존 작업을 보존합니다.
