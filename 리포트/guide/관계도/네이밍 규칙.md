# 네이밍 규칙

SampleProjectForUnity의 C# 명명 기준입니다.

| 대상 | 형태 | 예 |
| --- | --- | --- |
| 클래스·프로퍼티·메서드 | `PascalCase` | `PlayerController`, `IsMoving`, `SetOwner` |
| 비공개 필드 | `_camelCase` | `_owner` |
| 공개·보호 필드, 매개변수, 지역 변수 | `camelCase` | `owner`, `deltaTime` |
| 불리언 | `is`, `has`, `can`에 맞춰 형태 적용 | `_isMoving`, `CanJump` |
| 인터페이스·열거형 | `i`·`e` + `PascalCase` | `iManager`, `eBuffType` |
| 상수 | `UPPER_SNAKE_CASE` | `GROUND_STICK_SPEED` |

기존 `Initalize`, `PawnInfoAnchor`, 비공개 Inspector 필드 등 원문에 명시된 예외는 보존합니다. 이름을 바꾸기 전 호출부·재정의·씬·프리팹을 확인하고, 네임스페이스는 주변 코드에 맞춥니다.
