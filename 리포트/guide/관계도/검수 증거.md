# 검수 증거

| 확인할 결과 | 첨부할 자료 |
| --- | --- |
| 정적인 화면과 외형 | 실제 대상의 스크린샷 |
| 동작·상호작용·애니메이션 | 실제 조작·동작을 담은 GIF |
| 음향까지 확인해야 하는 동작 | 실제 소리가 포함된 영상 |
| 화면 결과가 없는 텍스트·설정 | 대조한 파일과 확인 결과 |

무엇을 언제 확인했는지 설명하고 시안·과거 캡처와 현재 결과를 구분합니다. 공개 자료에서 비공개 정보와 다른 작업 화면을 제외합니다. 필수 증거를 확보하지 못한 항목은 사유와 미확인 범위를 남깁니다.
