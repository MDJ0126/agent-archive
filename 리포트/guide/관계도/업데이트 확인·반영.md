# 업데이트 확인·반영

새 요청을 시작할 때, 작업을 재개하거나 문맥을 복구할 때, 최종 보고 전에 중앙 업데이트 기록을 확인합니다.

1. 중앙 저장소의 `리포트/check-updates.mjs`를 Node로 실행합니다. 현재 세션에서 이미 읽은 ID가 있으면 `--since <ID>`로 전달합니다.
2. 새 기록이 있으면 해당 기록에 연결된 지침 원문을 읽고, 현재 작업에 적용되는 내용을 반영합니다.
3. 원격 조회에 실패하면 알려진 지침으로 진행합니다. 원격 최신은 미확인으로 표시하고 다음 확인 시점에 다시 조회합니다.
4. 최종 보고에서 실제로 확인한 최신 ID와 미확인 범위를 구분합니다.
