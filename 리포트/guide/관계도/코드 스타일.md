# 코드 스타일

SampleProjectForUnity의 C# 작성 기준입니다.

## 형식과 배치

- 공백 4칸으로 들여쓰고 중괄호는 다음 줄에 둡니다. `if`·`else`에는 항상 중괄호를 씁니다.
- `switch`의 `case`·`default` 본문도 중괄호로 감싸고 레이블, 본문, `break`·`return`을 각각 줄에 둡니다.
- Unity 생명 주기 함수는 함수 영역 위쪽, 사용자 정의 함수와 콜백은 아래쪽에 배치합니다. 보통 길이의 호출은 한 줄로 씁니다.

## 역할과 주석

- 함수마다 목적 하나를 정하고 입력 범위, 실패 결과, 상태 변경, 이벤트를 확인합니다. 부모 초기화·정리 호출을 보존합니다.
- 공유 상태와 수명 관리는 클래스, 독립적인 값 묶음은 구조체를 검토합니다. 저장되는 열거형의 기존 숫자는 유지합니다.
- XML 요약은 여는 태그·설명·닫는 태그의 세 줄로 작성합니다. 한국어 ‘~한다.’ 문장으로 계약·전제·부작용·이유를 설명합니다.
