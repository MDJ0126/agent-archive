# 전역 작업별 지침 트리

전역 AGENTS.md에서 요청에 맞는 가지를 고릅니다. 공통 진입 문서 합계와 선택 경로 요약은 각각 UTF-8 4 KiB까지입니다. 여러 가지를 읽어야 하면 공통 내용을 한 번만 적용합니다. 필요한 원문의 관련 절을 열고 이전 문구를 대조할 때는 [전역 전문](../../AGENTS-reference.md)에서 검색합니다.

## 프로젝트 도입과 지침 수정

첫 승인된 쓰기 작업에서 기존 지침과 트리를 확인합니다. 필수 규칙·예외·이력을 보존하고 공통 및 선택 경로를 각각 UTF-8 4 KiB 이내로 요약합니다. 링크와 크기를 확인하고 보존이 어려우면 사용자에게 이유와 대안을 알립니다. 자동 로딩 한도는 16 KiB입니다.

## 구현과 도구 작업

- 작업 대상의 실제 진입점과 현행 구현을 확인합니다. Unity 및 다른 도구 작업은 해당 절을 열고 기존 이름과 코드 스타일을 따릅니다. 씬·UI·리소스를 함께 바꾸면 각 영역의 원문과 실행 경로를 따로 확인합니다.
- 현재 작업에 직접 해당하는 동작만 검증하고 미확인 상태를 남깁니다. 대형 파일, 앱 조작, 배포는 각 작업별 예외와 원본 보존 기준을 따릅니다.

## 에셋 제작과 검수

- 프로젝트 제작 지침에 지정된 입력·승인·인계·검수 기준을 확인합니다. CampGuardian은 캐릭터 제작 지침과 프로젝트 트리에서 시작합니다. 승인 범위와 실제 검수 증거를 대조합니다.
- 포커스를 보호하고 실제 결과를 직접 확인합니다. 시각·동작·음향은 결과 유형에 맞는 증거를 확보하고 미확인 범위를 기록합니다.

[결과 증거 상세](agent-execution.md#결과-증거) · [품질 점검](관계도/품질%20점검%20절차.md) · [검수 증거](관계도/검수%20증거.md)

## 보고와 게시

- 작업별 JSON v2를 작성하고 프로젝트 예외를 확인합니다. 커밋·푸시·배포·공개 접근을 따로 검증하며 미확인 항목을 명시합니다. 웹 변경은 해당 프로젝트 성능 기준과 게시 체크를 확인합니다.
- SNS 글은 승인본의 문체와 공개 범위를 문서에서 확인합니다.

[커밋·보고 상세](agent-execution.md#커밋과-중앙-보고) · [보고서 작성](authoring.md) · [프로젝트별 예외](관계도/보고%20예외%20프로젝트.md) · [SNS 가이드](관계도/SNS%20글쓰기%20가이드.md)

## 전역 설정과 동기화

- 설치본과 중앙본의 차이를 확인하며 최신 원격 규칙과 미완성 로컬 변경을 보존합니다. 변동된 지침·업데이트 항목·결과 보고를 함께 기록하고 설치본과 중앙본의 해시를 확인합니다.
- 스킬·CLI 선택과 평가 시점은 도구 선택 절에서, 설치 경로·해시·복원은 다른 PC 복원 절에서 확인합니다. 다른 PC의 반영과 새 세션 검증은 각각 확인할 때만 완료로 기록합니다.
