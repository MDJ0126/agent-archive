# 전역 작업별 지침 트리

전역 AGENTS.md에서 요청에 맞는 가지를 고릅니다. 공통 진입 문서 합계와 선택 경로 요약은 각각 UTF-8 4 KiB까지입니다. 여러 가지를 읽어야 하면 공통 내용을 한 번만 적용합니다. 필요한 원문의 관련 절을 열고 날짜가 지난 결정은 [전역 전문](../../AGENTS-reference.md)에서 검색합니다.

## 프로젝트 도입과 지침 수정

- 새 저장소의 초기화 또는 미적용 저장소의 첫 승인된 쓰기 작업에서 기존 루트·하위 지침을 조사합니다. 기존 규칙과 이력을 원문에 보존하고 루트에 공통 규칙과 작업별 트리 진입점을 둡니다. 기존 트리가 있으면 재사용합니다.
- 읽기 전용 작업에서는 현재 지침을 따르고 도입이 남아 있음을 알립니다. 충돌이나 바이트 예산 문제가 있으면 규칙을 임의로 덜어내기 전에 이유와 해결안을 사용자에게 알립니다.
- 수정 전 범위·예산·필수 규칙·원문 위치·검증 기준을 제시합니다. 모든 지침 수정에 요약과 원문 연결을 갱신하고 UTF-8 크기, 상대 링크, 충돌·예외 보존을 확인합니다. 공통 4 KiB는 설치된 전역 파일과 프로젝트 공통 진입 문서를 합산하고, 중앙 저장소에서 설치본과 같은 내용은 한 번만 셉니다.
- 자동 로딩 한도는 사용자 설정 최상위 `project_doc_max_bytes = 16384`입니다. 프로젝트별 파일을 바꾸기 전에 기존 설정과 지침을 확인합니다. 한도 변경이나 다른 기기의 설치가 필요하면 실제 반영 범위를 구분해 알립니다.

## 구현과 도구 작업

- 작업 대상의 실제 진입점과 현행 구현을 확인합니다. Unity 및 다른 도구 작업은 해당 절을 열고 기존 이름과 코드 스타일을 따릅니다. 씬·UI·리소스를 함께 바꾸면 각 영역의 원문과 실행 경로를 따로 확인합니다.
- 현재 작업에 직접 해당하는 동작만 검증하고 미확인 상태를 남깁니다. 대형 파일, 앱 조작, 배포는 각 작업별 예외와 원본 보존 기준을 따릅니다.

## 에셋 제작과 검수

- 프로젝트 제작 지침에 지정된 입력·승인·인계·검수 기준을 확인합니다. CampGuardian은 캐릭터 제작 지침과 프로젝트 트리에서 시작합니다. 승인 범위와 실제 검수 증거를 대조합니다.
- 포커스를 보호하고 실제 결과를 직접 확인합니다. 시각·동작·음향은 결과 유형에 맞는 증거를 확보하고 미확인 범위를 기록합니다.

[품질 점검](관계도/품질%20점검%20절차.md) · [검수 증거](관계도/검수%20증거.md)

## 보고와 게시

- 작업별 JSON v2를 작성하고 프로젝트 예외를 확인합니다. 커밋·푸시·배포·공개 접근을 따로 검증하며 미확인 항목을 명시합니다. 웹 변경은 해당 프로젝트 성능 기준과 게시 체크를 확인합니다.
- SNS 글은 승인본의 문체와 공개 범위를 문서에서 확인합니다.

[보고서 작성](authoring.md) · [프로젝트별 예외](관계도/보고%20예외%20프로젝트.md) · [SNS 가이드](관계도/SNS%20글쓰기%20가이드.md)

## 전역 설정과 동기화

- 설치본과 중앙본의 차이를 확인하며 최신 원격 규칙과 미완성 로컬 변경을 보존합니다. 변동된 지침·업데이트 항목·결과 보고를 함께 기록하고 설치본과 중앙본의 해시를 확인합니다.
- 스킬 설치·복원·평가는 전역 전문의 해당 절을 따릅니다. 다른 PC의 반영과 새 세션 검증은 각각 확인할 때만 완료로 기록합니다.
