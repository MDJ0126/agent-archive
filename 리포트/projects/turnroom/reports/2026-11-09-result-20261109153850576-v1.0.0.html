TurnRoom 변경 커밋과 Unity Asset Store 초안 바이너리 갱신

차단

Design Data Table과 Entity Forge의 바이너리를 기존 초안에 저장했습니다. TurnRoom 변경은 로컬에 커밋했으며 원격 main 푸시는 자동 승인 검토에서 차단됐습니다.

2026년 11월 10일 오전 12:38 KSTv1.0.0작업 결과

작업 결과

Design Data Table 2.0.3 및 Entity Forge 0.3.2-preview 초안에 현재 소스로 구성한 바이너리를 등록했습니다. TurnRoom 변경은 로컬 커밋 46968c72에 보존했습니다.

변경 내용

적용 내용

기존 패키지에서 각각 소스 파일 71개와 31개의 내용 차이를 확인해 최신 파일과 .meta로 두 패키지를 다시 구성했습니다. Unity와 브라우저를 열지 않고 기존 Unity Publisher 세션의 업로드 API를 사용했습니다. 최근 소스와 검토한 산출물을 커밋했으며 로컬 복구본·임시 빌드·과거 산출물은 제외했습니다.

대화 기록 (발언 시각 미기록)

  • 사용자: “최근 모든 작업 푸시하고, 갱신된 두 제품 다시 초안 바이너리 등록해줘, 나 컴퓨터 쓸거니깐 유즈 ㄴㄴ”
  • 사용자: “아 다시 시작해줘 수정할게 있어서 수정했었음 ㄱㄱ”
  • AI 요약: 수정 후 소스를 다시 확인해 패키지를 재구성했고, 두 초안의 저장과 TurnRoom 원격 푸시 차단을 구분해 알렸습니다.

검증

두 제품 모두 업로드 성공 후 Publisher 관리 API에서 초안 상태와 업로드 크기를 대조했습니다. Design Data Table 초안 1550964는 69,737,382바이트, Entity Forge 초안 1551034는 32,048,119바이트입니다. 패키지에서 소스와 메타데이터를 읽어 해시를 대조하고, 커밋에 저장된 바이너리와 Git Chunk 복원 결과의 SHA-256도 원본과 일치했습니다. TurnRoom 원격 main은 e8251761로 확인했습니다.

남은 사항

자동 승인 검토가 기본 브랜치의 대규모 이동·삭제를 이유로 TurnRoom 푸시를 차단했습니다. 검토 가능한 로컬 커밋은 46968c72입니다. 화면 사용 제한으로 Unity 공식 Validator, 에디터 실행 및 스크린샷 촬영은 미실행입니다. 검증된 교훈을 검토했으며 전역·프로젝트 지침은 변경하지 않았습니다.

작업 시간

  • 제안 시간: 초기 상태 확인 약 1분, 패키지 확인 후 업로드 약 4~8분
  • 실제로 완료된 시간: 2026-11-10 00:30:03 KST 재착수. 두 초안 저장 완료 00:36:36 KST (6분 33초). 전체 요청은 원격 푸시 차단으로 미완료입니다.
  • XERJ: 미사용 — rg와 Git, Publisher 응답, 패키지 압축 해제 결과를 사용했습니다.
