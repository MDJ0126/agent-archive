MIRO작업 결과

홈·게시글 OG 카드와 Google 검색 예시

검증 대기

홈과 개발일지 한 편의 링크 공유 이미지 2종을 제작하고 Google 일반 검색에서의 제목·설명 예시를 작성했습니다.

2026년 11월 10일 오후 6:46 KSTv1.0.0작업 결과

작업 결과

Affinity 3.3.3에서 편집 원본 두 개를 제작하고 재열기를 확인했습니다. 블로그 로컬 빌드에 경로별 OG 태그와 이미지가 생성됩니다.

적용 내용

게시글 카드

build.mjs의 socialMetadata에서 두 경로에 사이트명, 제목, 설명, 절대 이미지 URL을 추가합니다.

const card = socialImages.get(canonical);
if(!card) return '';
const url = new URL(canonical, settings.url).href;
const image = new URL('/social/'+card.file, settings.url).href;

대화 요약

  • 사용자 요청 원문: “사이트 OG 제작과, 구글에서 검색햇을 때 어떻게 노출되는지 보여줄래? 게시글이랑 그냥 여기 루트 사이트 검색 햇을 때 나오는 예제”
  • AI: 홈과 개발일지 한 편의 메타데이터를 확인했습니다. 파일 저장은 Affinity 앱의 저장 대화상자를, JPEG 생성은 Affinity MCP의 spread 렌더링을 사용했습니다.

검증

공개 HTML에서 홈 제목 MIRO, 게시글 제목 첫 접속에 50MB가 들던 웹 빌드 줄이기 · 미로와 설명을 확인했습니다. Google 검색 예시는 홈 미로의 개발노트 / 개발일지와 게임, 게임 개발, AI 동향, 게시글 첫 접속에 50MB가 들던 웹 빌드 줄이기 · 미로 / 전송량과 고해상도 렌더 비용을 별도로 낮췄습니다.입니다. 홈 예시는 로컬 HTML 기준입니다. node build.mjs로 173개 경로를 생성한 뒤 두 대상 HTML의 OG 유형, 절대 URL, JPEG의 원본과 빌드 복사본 바이트 일치를 확인했습니다. 원본은 1200×630, JPEG는 Affinity 렌더러 제한에 따라 1024×537입니다. 공개 페이지 변경 전에는 OG 메타데이터가 없었으며 작업 결과는 페이지 본문에 표시되는 UI 변경이 없습니다.

남은 사항

블로그 본 배포 및 실제 Google 검색 노출은 미확인입니다. 예시는 메타데이터를 기반으로 작성했습니다. 교훈 검토 결과 기존 전역·프로젝트 지침 변경 사항은 없습니다.

작업 시간

  • 제안 시간: 초기 확인 약 30초, 이어서 1~2분 예상
  • 실제로 완료된 시간: 18:39:23 KST 시작, 18:45:34 KST에 카드와 로컬 검증 완료(약 6분 11초). 보고서 공개는 별도.
  • XERJ: 미사용 — 코드 검색 근거가 제공되지 않았습니다.
