적용 내용

글 상세 폭, 챕터 간격, 상단 브랜드, 홈 광고 영역 제어를 수정했습니다. 대화 요약: 사용자가 글 가로 폭과 섹션 여백을 지적하고, “사이트 파비콘이랑 로고랑 따로 노니깐 한쪽으로 맞춰주고”, “홈페이지에서 특정 단축키”를 요청했습니다. 응답에서 Alt+Shift+A와 브라우저에 선택을 저장하는 방식을 안내했습니다. 발언 시각은 미기록입니다.

검증

운영 Chrome의 동일한 1520px 화면에서 상세 폭 820 → 1060px, 본문 H2 위 여백 30 → 60px, 상단과 탭에 동일 SVG 연결을 확인했습니다. 초기 꺼짐, 단축키 버튼 표시, 켜짐, 재진입 유지, 다시 끄기를 확인했습니다. 사이트 846페이지, 게시물 791개, 이미지 참조 7859건 검사에서 깨진 참조는 0건입니다.
