## 작업 결과

일반 주소가 복구됐다는 앞선 안내를 정정합니다. 연결 응답을 303 즉시 이동에서 200 문서와 동일 사이트 이동으로 변경했고 HEAD 연결 요청도 처리합니다. 실제 iPhone 일반 주소 접속은 완료가 아닙니다.

## 변경 내용

### 적용 내용

폰 일반 주소 요청에서 등록 정보 포함 여부만 기록하는 비식별 진단을 추가했습니다. 등록 ID·IP·전체 사용자 에이전트는 진단 출력에 기록하지 않습니다. 유효 연결 문서가 저장 응답을 받은 다음 같은 사이트로 이동하도록 변경했습니다. 허용 ID 두 개와 일반 403은 유지합니다.

## 검증

실제 서버에서 iPhone ID 연결 GET·HEAD 각각 200 문서와 등록 응답을 확인했습니다. iPhone ID를 포함한 일반 주소 200, ID 없는 요청 403을 확인했습니다. 진단 수집은 자체 요청으로 작동을 확인했으나 이번 확인 중 사용자 폰 요청은 식별하지 못했습니다. 실제 iPhone에서 일반 주소가 열렸다고 보고하지 않습니다. node --check 통과, 테스트 모음 미실행.

## 남은 사항

실제 iPhone 일반 주소 재접속과 사용 브라우저는 미확인입니다. 사용자가 브라우저 종류 질문에 답하지 않았고 일반 주소 403을 재확인했습니다. 서버에서 사용자 폰 요청을 아직 확인하지 못해 원인을 확정하지 않습니다. 임시 실시간 요약 조회를 다음 사용자 시도 확인까지 유지합니다. 폰 접속 문제를 완료로 변경하지 않습니다. 지침 변경 없음.
