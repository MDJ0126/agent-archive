## 작업 결과

중앙 보고서 제출 단계에 같은 프로젝트의 완료·부분 완료 작업과 중앙 등록·게시 목록을 대조하는 절차를 추가했습니다.

## 변경 내용

### 적용 내용

근거와 공개 범위가 확인된 누락분은 작업별 JSON v2로 작성해 같은 제출에 포함합니다. 기존 보고서가 공개 목록에 없으면 배포 상태를 확인하고, 누락분의 근거 또는 공개 범위가 불확실하면 그 사유를 남깁니다.

## 검증

보고와 게시 요약, 실행 지침, 작성 가이드, 업데이트 공지에 같은 제출 기준이 반영됐는지 대조했습니다. 문서 규칙 변경으로 별도 화면 증거는 없습니다.

## 남은 사항

후속 작업에서 실제 누락 건을 이 절차로 등록하는 사례는 아직 검증하지 않았습니다.
