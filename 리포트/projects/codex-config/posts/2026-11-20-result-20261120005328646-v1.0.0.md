## 작업 결과

설치본·저장소 원문 동기화 및 해시 비교. 게시 상태는 별도 확인.

## 변경 내용

### 적용 내용

전역 지침에 보고서 게시 미디어만 채팅에 직접 표시하고 보고서 링크를 함께 제공하는 규칙을 추가했습니다. 상대 경로는 보고서 URL 기준으로 절대 HTTPS 변환하며 GET 성공·미디어 종류·내용을 확인합니다. PC 로컬 경로와 raw 우회 주소는 사용하지 않고 배포 대기·404는 미완료로 기록합니다. 업데이트 게시판007에 같은 변경을 등록했습니다.

## 검증

설치본과 저장소 원문의 SHA256 일치 확인. 대상 지침·게시판·이 보고서만 별도 Git 인덱스로 게시해 기존 사용자 변경을 보존합니다. 순수 텍스트 설정 작업으로 시각적 제품 변경이 없어 촬영 대상이 없습니다. 원문·설정 대조를 근거로 기록하며 촬영 완료로 간주하지 않습니다. 테스트 작성·실행 없음. SkillEvaluator·CLI-Anything 적용 대상 아님.

## 남은 사항

지침 배포와 공개 HTTPS 접근은 publication 기록을 따릅니다. 이미 실행 중인 다른 대화의 자동 적용은 보장하지 않습니다.
