## 작업 결과

새 스킬 최초 등록 시에만 quality-check와 harness-check를 자동 실행합니다. 사용자의 명시적 평가 요청은 요청한 범위에서 수행합니다.

## 변경 내용

### 적용 내용

전역 상시 적용 규칙과 다른 PC 복원 후 확인 규칙 두 곳을 함께 수정했습니다. 스킬 설치 정본·해시 확인·누락 복원 기능은 유지했습니다. 업데이트 ID 2026-11-20-011으로 기록했습니다.

## 검증

관련 지침 원문과 Restore/Export/Sync 스크립트 검색으로 조건을 대조했습니다. 스크립트 자체에 SkillEvaluator 자동 호출이 없어 코드 변경은 필요하지 않았습니다. 이번 작업은 새 스킬 추가가 아니므로 SkillEvaluator를 실행하지 않았습니다. 순수 지침 설정 작업이라 실제 UI 시각 결과가 없어 캡처를 생성하지 않았습니다.

## 남은 사항

이미 실행 중인 다른 세션이 새 지침을 읽기 전의 자동 반영은 미확인입니다.
