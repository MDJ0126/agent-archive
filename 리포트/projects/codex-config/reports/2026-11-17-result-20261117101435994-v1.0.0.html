IP 허용 제거 및 등록 기기 2대 외 일반 403 적용

완료

IP 허용을 제거하고 PC·iPhone 기기 ID만 허용합니다. 비인가 요청에는 연결 안내 없는 403 페이지만 반환합니다.

2026년 11월 17일 오후 7:14 KSTv1.0.0작업 결과

작업 결과

접근 기준을 등록 기기 ID 두 개로 제한했고 IP 항목을 자체 저장소에서 제거했습니다. 공개 기기 등록 화면과 접근 조건 설명을 제거했습니다.

변경 내용

적용 내용

허용 해시 설정에서 IP를 제거했습니다. 요청 판별은 device 범위의 등록 ID와 일치 여부만 사용합니다. 기존 IP 레코드는 자체 저장소에서 삭제합니다. 루트·보고서·등록 경로에서 미인가 요청은 같은 일반 403을 반환합니다. 본인 기기 연결은 사용자에게 전달한 개별 링크로 처리합니다.

검증

실제 서버에서 이전 허용 IP로 접속해도 ID 없는 루트·보고서·등록 경로는 모두 403이며 연결 경로 힌트가 없었습니다. PC·iPhone ID 각각 관리 화면 200, 잘못된 ID 403을 확인했습니다. IP 항목이 관리 화면에서 제거됐습니다. 소스 구문 검사 통과. 별도 테스트 모음은 실행하지 않았습니다.

남은 사항

실제 PC·iPhone 브라우저에서 개별 연결 링크를 연 결과는 사용자 확인 전입니다. 판별 대상은 가져온 식별값이며 복제 불가능한 물리 기기 인증을 추가한 것은 아닙니다. 공개 저장소 원문은 그대로입니다. 지침 변경은 없습니다.
