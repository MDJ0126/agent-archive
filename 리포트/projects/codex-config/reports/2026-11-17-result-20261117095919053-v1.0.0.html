중앙 보고 사이트에 기존 관리 기기 접근 제한 적용

완료

PC·iPhone 기기 ID와 등록 IP를 중앙 사이트에 독립 저장하고 서버에서 접근을 제한했습니다. 기존 공개 보고 주소는 잠금 안내로 전환했습니다.

2026년 11월 17일 오후 6:59 KSTv1.0.0작업 결과

작업 결과

독립 중앙 보고 서버와 접근 관리 화면을 배포했습니다. 등록 정보를 자체 저장소로 복사했으며 포폴 소스·연결 설정은 원복했습니다. 기존 공개 페이지 잠금 배포도 완료했습니다.

변경 내용

적용 내용

기기 2건과 IP 1건을 비공개 설정으로 가져왔습니다. 기기 연결 후 HttpOnly·Secure 쿠키로 식별하며 등록 IP도 허용합니다. 관리 화면에서 항목별 접근 해제와 재허용을 처리합니다. 포폴·블로그와 운영 의존성을 분리했습니다. 기존 공개 배포는 보고서·원문·첨부를 제외한 잠금 안내로 변경했습니다.

검증

실제 중앙 주소에서 등록 IP 관리 화면 HTTP 200, 등록 PC 연결 POST 303 및 쿠키 발급, 미등록 기기 연결 POST 403을 확인했습니다. 변경 소스 node --check 통과. 최종 버전의 실제 iPhone 브라우저 조작은 미확인입니다. 테스트 모음은 실행하지 않았습니다. 최종 독립 서버에서 등록 PC·iPhone 쿠키 각각 HTTP 200, 미등록 쿠키 HTTP 403을 실제 확인했습니다. 기존 공개 루트는 잠금 안내이며 기존 개별 보고서는 HTTP 404입니다.

남은 사항

최초 다른 도메인의 기기 쿠키는 공유되지 않아 중앙 사이트에서 1회 기기 연결이 필요합니다. 기기 ID는 복사 가능한 식별값이며 물리적 기기에 대한 암호학적 증명은 아닙니다. 등록 IP는 같은 공인 IP의 다른 기기도 허용합니다. GitHub 공개 저장소의 원문과 과거 이력은 비공개로 바꾸지 않았습니다. 향후 보고서 수정 시 보호 서버의 자산도 별도로 배포해야 합니다. 일반 보안 교훈의 추가 지침 변경은 하지 않았습니다.
