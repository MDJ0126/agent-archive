변경 내용

적용 내용

공개 배포 워크플로 두 개를 원래 package-site.mjs 및 .site 산출물로 되돌렸습니다. 원래 공개 응답 검증 단계를 복원했습니다. 추가한 기기 제한 Worker 소스·설정과 공개 잠금 안내 패키징 소스를 삭제했습니다. 이번에 만든 Cloudflare 서버 tracefolio-private를 삭제했습니다. 기존 보고서·이력·첨부와 다른 세션 변경은 보존했습니다.

검증

복원 커밋 faf5adc4의 GitHub Pages 배포 성공을 확인했습니다. 실제 원래 주소 https://mdj0126.github.io/codex-config/index.html 에서 등록 정보 없이 보고서 목록 HTTP 200과 잠금 안내 제거를 확인했습니다. 기존 개별 DotAction 보고서도 HTTP 200이며 403 페이지가 아니었습니다. Wrangler가 Successfully deleted tracefolio-private를 반환했습니다. 포폴·블로그 설정은 이번 작업에서 변경하지 않았습니다. 별도 테스트 모음은 수동 실행하지 않았으며 기존 자동 배포 검사는 유지했습니다.

남은 사항

폐기한 tracefolio-private 주소는 사용하지 않습니다. 원래 GitHub Pages 주소를 사용합니다. 브라우저에 남은 기기 연결 정보는 원래 공개 사이트의 접근에 사용되지 않습니다. 일반 검증 지침과 중복돼 지침 변경은 하지 않았습니다.
