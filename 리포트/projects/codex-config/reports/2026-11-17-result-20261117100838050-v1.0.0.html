작업 결과

기존 링크를 같은 경로의 보호 사이트로 연결하도록 수정했습니다. 원본과 패키지에 모두 없는 HTML은 보고서 목록으로 안내합니다.

변경 내용

적용 내용

공개 잠금 안내에 고정 목적지 링크만 있던 것을 현재 경로·쿼리·해시를 보존하는 이동으로 수정했습니다. 인증 뒤 최신 보고서 원본을 읽고 기존 패키지를 대체 경로로 사용합니다. iPhone 최초 연결 링크를 사용자에게 전달했습니다.

검증

첨부 경로는 원본·보호 패키지에서 미존재 또는 HTTP 404임을 확인했습니다. 수정 후 실제 같은 경로는 보고서 목록 HTTP 200으로 이어집니다. 실제 iPhone ID 연결 POST는 303과 보안 쿠키 발급을 확인했습니다. 소스 node --check와 보고서 빌드 통과. 공개 주소 자동 이동은 소스 생성 후 배포 상태를 확인합니다.

남은 사항

실제 iPhone 브라우저에서 최초 연결을 완료했는지는 미확인입니다. 존재하지 않는 보고서 원본을 복구했다고 보고하지 않습니다. 공개 저장소 원문은 그대로이며 새로운 접근 권한은 추가하지 않았습니다. 일반 지침 추가는 하지 않았습니다.
