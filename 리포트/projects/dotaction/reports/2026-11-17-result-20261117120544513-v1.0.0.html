적용 내용

해시 기반 안정 ID와 원문/출처 카탈로그, 언어별 JSON, 번역 누락 집계를 추가했습니다. 외부 서비스 호출 없이 동작하는 Python 빌더가 직접 작성한 TSV/설정 JSON을 병합하고 printf·이름 자리표시자를 검사합니다. 선택한 언어만 Godot Translation에 등록하고 데이터 문자열을 원문 사본으로부터 갱신합니다. 설정 목록에서 언어를 선택·저장하며 마을 UI를 갱신합니다. 클래스/장비/증강/상태이상/주요 NPC 소개 문구를 직접 번역했습니다. 전투 로그는 한국어 조사 조립 대신 언어별 완성 문장과 이름 자리표시자로 변경했습니다. 중국어용 Fusion Pixel 글꼴과 원본 라이선스를 보존했습니다. 제작용 카탈로그와 누락 집계는 내보내기에서 제외했습니다. 최초 외부 번역 경로 선택은 사용자 의도에 맞지 않았으며 자동 검토가 전체 전송을 거절했습니다. 연결 확인에서 '설정' 한 단어만 전송됐고 전체 문구는 전송되지 않았습니다. 사용자의 외부 번역 거부 후 네트워크 번역 코드를 삭제하고 직접 번역만 유지했습니다. 공통 지침 추가/변경 없음.
