적용 내용

Aseprite 기준의 아트 규격 v0.1과 README·문서·공통 팔레트를 구성했습니다. 이번 결과는 제작 기준이며, 실제 캐릭터·카드 그림은 아직 제작하지 않았습니다.

스타일은 어두운 외곽선 + 황동 장비 + 청록 에너지 + 보라 증강 효과로 잡았습니다.

대상 규격
플레이어·일반 적 32×32, 발바닥 기준점 통일
공유 심벌 16×16, 슬롯·카드에서 동일 원본 사용
슬롯 셀 32×32
카드 프레임 96×128, 글자·수치는 엔진에서 표시
공통 표현 32색, 1px 외곽선, 왼쪽 위 광원

전투 시점은 옆모습 임시안입니다. 시점 확정 후 캐릭터를 대량 제작하도록 명시했습니다.

아트 정리는 Aseprite + 폴더 + 에셋 목록 + Git으로 시작합니다.

  • art/source/: 편집 가능한 .aseprite 원본
  • art/exports/: 게임용 PNG·애니메이션 JSON
  • art/palettes/: 공통 팔레트
  • art/catalog/: 에셋 ID·경로·승인 상태
  • art/previews/: 전체 스타일 비교 화면

먼저 README (당시 로컬 자료; 공개 첨부 미확인)를 보시면 됩니다. 상세 내용은 아트 규격 (당시 로컬 자료; 공개 첨부 미확인), 첫 제작 세트 (당시 로컬 자료; 공개 첨부 미확인), 제작·정리 절차 (당시 로컬 자료; 공개 첨부 미확인)에 담았습니다. Aseprite용 팔레트 (당시 로컬 자료; 공개 첨부 미확인)도 만들었습니다. GPL 불러오기는 공식 지원 형식입니다.

색상 32개의 중복 여부·팔레트 파일 일치·문서 링크는 확인했습니다. Aseprite 실제 불러오기, 그림 제작·시각 검증, 커밋·푸시·공개 보고서 배포는 미완료입니다.
