직접 번역 지침 추가와 11개 언어 UI 잘림 빠른 검수

검증 대기

프로젝트 번역 품질 기준을 명시하고 마을 설정·라벨 줄바꿈·카드·NPC 대화의 잘림과 넘침을 수정했습니다.

2026년 11월 17일 오후 9:23 KSTv1.0.0수정사항

작업 결과

프로젝트 지침 추가·발견 UI 수정·지정 화면 11개 언어의 Godot 배치 확인을 완료했습니다. 전체 게임 번역 완료나 모든 화면 검수 완료를 뜻하지 않습니다.

변경 내용

적용 내용

AGENTS.md에 문맥·수치·NPC 말투에 맞는 직접 번역, 외부 번역 서비스 무단 전송 금지, 완성 문장/자리표시자, 미번역/초안/검수 구분 및 실제 Godot 다국어 배치 검수를 추가했습니다. Label의 줄바꿈을 텍스트/크기보다 먼저 설정하고 트리 편입 후 폭을 재확정하여 긴 문장의 최소 폭 확장을 막았습니다. 마을 설정 버튼48→100px 및 금화 위치, 클래스/성장 정보와 조작 안내 영역을 조정했습니다. 언어 목록 선택표시의 누락 글리프를 ASCII로 바꾸고 행 간격을 확보했습니다. 카드 제목은 고정 폭 RichText 줄바꿈, 긴 본문은 4px 픽셀 스크롤바로 끝까지 읽을 수 있게 했습니다. NPC 대사 영역48px/선택 버튼36px로 조정하고 언어 변경 시 기존 NPC line도 갱신합니다. 일본어 증강 용어를 加護, 프랑스어 방패 공격을 Coup de bouclier로 다듬고 여관 서비스 버튼 표현을 간결하게 정리했습니다. 글꼴 크기는 축소하지 않았습니다.

검증

실제 Godot4.7.2/640×360에서11개 언어의 마을·설정·언어 목록·NPC14명·대표 증강3개의 실제 글꼴/컨트롤 배치를 검사했습니다. 수정 후 LAYOUT_FINDINGS [] 확인. OpenGL 실제 렌더에서 독일어 설정, 중국어 언어 목록, 프랑스어 카드와 NPC 대사를 이미지로 직접 대조했습니다. 초기 검사 스크립트의 잘못된 증강 ID는 실제 테이블 키로 수정했고 임시 실행 세션을 종료했습니다. 렌더 세션 종료 시3개 텍스처 RID 정리 경고가 있었으며 플레이 기능 오류로 단정하지 않습니다. 별도 전체 회귀 테스트 미실행.

남은 사항

인벤토리·상점 상세·전투 툴팁 전체, 모든 클래스/수치 조합 및 원어민 검수는 미확인입니다. 전체 번역은 기존과 같이 미완료이며 선택 언어당281개 직접 번역 상태입니다. EXE 빌드·게임 푸시/배포 미실행. 중앙 보고 푸시·배포는 별도 확인합니다.
