캠프 가디언수정사항

대사 출력 자동 스크롤과 휠 이동량 확대

완료

출력 중인 마지막 글자를 따라 스크롤하고 휠 한 칸 이동량을32px로 높였습니다.

2026년 11월 18일 오후 2:25 KSTv1.0.0수정사항

작업 결과

구현·저장 및 실제 Godot 헤드리스 대사 출력·휠 입력 확인 완료.

변경 내용

적용 내용

npc_dialogue.gd에서 현재 출력된 마지막 유효 글자의 Label.get_character_bounds를 확인해 대사 영역 아래로 넘어갈 때 자동 스크롤합니다. 전체 대사 즉시 표시에도 마지막 글자를 따라갑니다. 휠 이벤트는 한 칸32px로 처리하며 스크롤바 custom_step도32로 맞췄습니다. 수동 휠 조작 뒤1.5초 동안 자동 추적을 쉬어 이전 대사를 읽을 수 있습니다. 출력 글자가 바뀔 때만 추적해 출력 완료 뒤 수동 스크롤을 되돌리지 않습니다. 버블 크기·카메라는 유지합니다. 공통 지침 변경 없음.

검증

Godot 4.7.2 실제 boot.tscn 실행·미라 대화 출력. DIALOGUE_FOLLOW chars=54, scroll=40, last_bounds y=54/h=15. 실제 뷰포트 휠 입력 이벤트 전달 후 DIALOGUE_WHEEL scroll=32, manual_pause=true, data.errors=[]. 종료코드0, 오류 없음. 별도 테스트·회귀 테스트 미실행. API 동작은 Godot 공식 Label 문서의 get_character_bounds를 참고했습니다.

남은 사항

GUI 육안 확인·실제 물리 마우스 체감·다국어 전체는 미확인. 프로젝트 빌드·커밋·푸시·배포 미실행. 중앙 보고 게시 상태는 별도 확인.
