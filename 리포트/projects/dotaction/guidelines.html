DotAction 프로젝트 지침

  • Unity 6000.0.83f1 / URP 2D, 기준 화면 640×360, PPU16입니다.
  • 아트 규격과 32색 원본은 프로젝트 docs와 art/palettes를 기준으로 합니다.
  • .aseprite 원본은 art/source, 파생 출력은 art/exports, Unity 사본은 Assets/Art입니다. 동기화할 때 .meta를 보존합니다.
  • 캐릭터는 32×32, 공통 심벌은 16×16이며 슬롯·카드에서 같은 원본을 공유합니다.
  • ArtReference는 정적 스타일 확인 씬입니다. 전투·슬롯 추첨·증강 로직이 구현됐다고 보고하지 않습니다.
  • 정적 UI는 씬에 저장합니다. 최초 씬 구성 도구는 기존 씬을 덮어쓰지 않습니다.
  • 이번 환경의 실제 캡처에서 기본 머티리얼의 텍스처 표시 문제가 재현되어 자산별 명시적 URP 2D Unlit 텍스처 연결을 저장했습니다. 다른 프로젝트의 보편적 오류라고 일반화하지 않습니다.
  • TurnRoom·polyperfect는 사용자 의도로 추가된 자산입니다. 이번 작업에서 수정·삭제하지 않습니다.
  • 근거: 이번 아트 제작 결과 보고 및 첨부된 실제 Aseprite·Unity 화면과 원본 재열기 기록.

Sprite Studio

  • 공통 실행·보고 기준은 사용자가 제공한 전역 AGENTS.md를 따른다.
  • 외부 생성 이미지 원본을 보존한다. Sprite Studio 원본은 art/source/sprite-studio의 .sprite.json이며 Aseprite 사본 수정은 자동 역동기화되지 않는다.
  • MCP와 UI는 동일한 처리 코드를 사용한다. MCP 수정 전 사용자의 미저장 문서를 보존하고 revision 충돌을 우회하지 않는다.
  • 격자·팔레트 보정과 캐릭터 형태의 일관성은 구분한다. 기준 그림·장비·캔버스·발 위치를 실제 프레임에서 대조한다.
  • 시트에는 프레임 크기·태그·시간을 보존한다. Unity의 Studio 출력 폴더는 Multiple 임포트하고, 기존 일반 픽셀 아트의 Single 설정은 유지한다.
  • Unity 시트 가져오기 변경은 실제 배치 실행 로그와 생성된 .anim/.controller/.prefab으로 확인한다. 플레이 화면을 보지 않았다면 게임 내 표시를 완료로 기록하지 않는다.

근거: 2026-11-16 실제 MCP·브라우저·Aseprite·Unity 배치 실행 기록. 샘플 환류는 편집 도구 흐름 안정화 후 검토한다.

프로젝트 폴더

  • Assets 안에 프로젝트 이름을 반복하는 상위 폴더를 만들지 않습니다.
  • 아트·씬·데이터·프리팹·머티리얼·애니메이션은 Assets의 용도별 폴더를 사용하고 코드는 Assets/Scripts/Runtime, Assets/Scripts/Editor에 둡니다.
  • 외부 자산의 TurnRoom, polyperfect 원본 분류는 보존합니다. 이동 시 파일의 .meta와 GUID를 함께 보존하고 빌드 씬 및 도구의 문자열 경로도 갱신합니다.
  • 근거: 사용자의 중복 내부 프로젝트 폴더 정리 요청과 이동 전후 GUID 대조 기록.
