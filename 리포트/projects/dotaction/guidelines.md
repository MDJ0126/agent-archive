# DotAction 프로젝트 지침

- 현재 엔진은 Godot 4.7.2이며 루트 project.godot이 진입점입니다.
- 현재 프로젝트 AGENTS.md와 docs의 관련 제작 지침을 따릅니다. 과거 Unity 기록은 현재 엔진 기준이 아닙니다.
- 배우·타일·FX는 프로젝트 정규화 도구를 거친 파생 출력만 연결하고 원본을 보존합니다.
- 결과 보고는 전역 상시 보고 규칙에 따라 작업별로 중앙 아카이브에 게시합니다.
- 과거 복원 보고는 당시 기록이며 최신 실행·외관·청감 검증을 의미하지 않습니다.

## 2026-11-18 · SNS용 영상의 제목 비공개와 간결한 편집
- 사용자가 공개를 명시적으로 승인하기 전까지 SNS용 영상·썸네일·자막·음성·게시 문구·공유용 파일명에 게임 제목, 프로젝트명, 로고를 노출하지 않습니다. 게임 화면 안에 포함된 제목도 확인해 제외하거나 가립니다. 제작 요청은 SNS 게시 승인이 아닙니다.
- 개발 쇼츠는 실제 게임 화면과 간단한 설명 자막 중심으로 제작합니다. 상하 제목, '지금 만드는 게임', 단계/스텝 표시·아이콘·진행 바, 작은 출처·날짜·제작 도구 설명은 영상에 넣지 않습니다. 원본과 출처는 편집 자료 내부에만 보존합니다.
- 첫 쇼츠의 소개 순서는 유지하고 영상·자막·편집 프로젝트를 함께 수정합니다.
- 2026-11-18 후속 보정: 게임 화면을 크게 보여주고 간단 자막은 바로 아래의 하단 안전 영역에 붙입니다. 우측 SNS 버튼·하단 설명 영역과 자막 겹침을 피하며 실제 플랫폼 미리보기 확인 여부를 구분합니다. 상단 영상 번호(예: DEVLOG / 001)는 허용하며 게임 제목·단계 표시·출처 설명은 계속 제외합니다.

근거: 사용자가 제목 비공개 지시를 재확인하고 첫 쇼츠의 부가 표시 제거와 단순한 구성을 요청했습니다.
