# DotAction 프로젝트 지침

- 현재 엔진은 Godot 4.7.2이며 루트 project.godot이 진입점입니다.
- 현재 프로젝트 AGENTS.md와 docs의 관련 제작 지침을 따릅니다. 과거 Unity 기록은 현재 엔진 기준이 아닙니다.
- 배우·타일·FX는 프로젝트 정규화 도구를 거친 파생 출력만 연결하고 원본을 보존합니다.
- 결과 보고는 전역 상시 보고 규칙에 따라 작업별로 중앙 아카이브에 게시합니다.
- 과거 복원 보고는 당시 기록이며 최신 실행·외관·청감 검증을 의미하지 않습니다.

## 2026-11-18 · SNS용 영상의 제목 비공개와 간결한 편집
- 사용자가 공개를 명시적으로 승인하기 전까지 SNS용 영상·썸네일·자막·음성·게시 문구·공유용 파일명에 게임 제목, 프로젝트명, 글자 로고를 노출하지 않습니다. 게임 화면 안에 포함된 제목도 확인해 제외하거나 가립니다. 2026-11-18 사용자가 요청한 글자 없는 게임 심벌 아이콘은 상단에 사용할 수 있습니다. 제작 요청은 SNS 게시 승인이 아닙니다.
- 개발 쇼츠는 실제 게임 화면과 간단한 설명 자막 중심으로 제작합니다. 상하 제목, '지금 만드는 게임', 단계/스텝 표시·아이콘·진행 바, 작은 출처·날짜·제작 도구 설명은 영상에 넣지 않습니다. 원본과 출처는 편집 자료 내부에만 보존합니다.
- 첫 쇼츠의 소개 순서는 유지하고 영상·자막·편집 프로젝트를 함께 수정합니다.
- 2026-11-18 후속 보정: 게임 화면을 크게 보여주고 간단 자막은 바로 아래에 붙입니다. 자막과 중앙 요소는 영상의 가로 중앙 정렬을 유지하며, 세이프 에어리어 때문에 왼쪽으로 당기지 않습니다. 영상 중심을 기준으로 대칭인 텍스트 폭 안에서 크기·줄바꿈으로 안전 영역을 지킵니다. 실제 플랫폼 미리보기 확인 여부를 구분합니다. 상단에는 글자 없는 게임 아이콘·'개발 일지'·영상 번호와 절제된 디자인을 허용하며 게임 제목·단계 표시·출처 설명은 계속 제외합니다.

근거: 사용자가 제목 비공개 지시를 재확인하고 첫 쇼츠의 부가 표시 제거와 단순한 구성을 요청했습니다.


## 2026-11-18 · 모든 몬스터의 전용 공격과 픽셀 FX
- 새 몬스터·보스를 만들거나 기존 종을 추가할 때 외형만 등록하지 않습니다. 종별 전용 공격 ID·준비/발동/회수 동작·실제 판정·공격 후 빈틈·대응법·전용 픽셀 FX를 같은 작업에서 구현합니다. 역할과 등급에 필요하면 복수 공격·연계·잔류 효과를 제공합니다.
- 공용 실행 구조와 PixelFX 코어·라이선스 자원은 재사용할 수 있지만, 기존 공격/FX의 이름·색·수치만 바꿔 종별 전용 구현이 완료됐다고 기록하지 않습니다. 공격 형태·타이밍·이동/발사/지속 방식과 FX의 실루엣·움직임·모티프를 종의 외형과 역할에 맞춥니다.
- 예고는 실제 원·부채꼴·직선·고리·다중 지점 판정과 동일한 위치/방향/크기/고정 여부/시계를 사용하고 배우·오브젝트 아래에 표시합니다. 발사점·무기 끝·충돌·잔류/사망 발동을 실제 게임 배우 기준으로 연결합니다. 강한 상태이상·사망·명시 취소는 준비와 예약 발동을 함께 취소하며 이미 발사/설치된 효과의 유지 규칙을 구분합니다.
- 원본·제작 코드·PNG/JSON·피벗·타이밍·해시·라이선스를 보존하고 tools/normalize-art.mjs를 거친 프로젝트 소유 FX만 연결합니다. 데이터 로딩에서 전용 공격·FX 누락을 오류로 드러내며 새 종을 기본 공격/공용 효과로 조용히 대체하지 않습니다.
- 같은 작업에서 docs/design/monster-attacks.md 및 영향받는 전투/아트 제작 문서·데이터 시트·웹 이미지도 갱신합니다. 실제 Godot 공격/FX 렌더 GIF 또는 영상을 남기며 기능 확인·시각 확인·미확인을 구분합니다. 기획 보스는 실제 구현 전까지 planned를 유지합니다.

근거: 사용자가 모든 기존 몬스터와 향후 제작 몬스터에 전용 공격·필요한 복수 공격·전용 픽셀 FX를 구현하도록 요청했습니다.
