## 작업 결과

SHA-256 계산을 .NET으로 바꿔 기존 빌드 캐시를 그대로 사용합니다.

## 변경 내용

### 적용 내용

대시보드 창 빌드 스크립트의 Get-FileHash 의존을 제거했습니다. 프로젝트 main의 2ebe23de에 반영했습니다.

## 검증

Windows PowerShell 5.1에서 Get-FileHash를 호출하면 실패하는 조건으로 빌드 캐시 경로, 숨긴 WebView2에서 실제 페이지 로딩과 모달 유지, 창 및 소유 서버 종료를 확인했습니다. 오류 문구를 제거하는 실행 경로 수정으로 신규 화면 구성은 없습니다.

## 남은 사항

사용자 트레이의 실제 창 동작과 공개 배포는 별도 확인 범위입니다.
