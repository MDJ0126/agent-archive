## 변경 내용

### 적용 내용

네, **표준 Unity Asset Store EULA가 적용되는 에셋은 Godot에서도 사용할 수 있습니다.** 상업용 게임에 포함하는 것도 가능합니다. 표준 약관은 사용 엔진을 Unity로 한정하지 않습니다. [공식 EULA §2.2.1](https://unity.com/legal/as-terms)

다만 다음은 확인하셔야 합니다.

- **별도 라이선스:** 상품에 `Non-standard EULA` 또는 `Restricted Asset` 표시가 있으면 해당 조건을 확인해야 합니다. [공식 FAQ](https://assetstore.unity.com/browse/eula-faq)
- **재배포 제한:** 게임에 포함하는 것은 가능하지만, 에셋 원본을 따로 공유하거나 재판매하는 것은 제한됩니다. [공식 EULA](https://unity.com/legal/as-terms)
- **기술적 호환성:** 이미지·모델·음원은 가져와 활용할 수 있지만, Unity 전용 스크립트·셰이더·프리팹은 Godot에 맞게 변환하거나 다시 구현해야 합니다.

구매하신 **에셋 링크를 주시면 해당 상품의 예외 조건까지 확인해 드리겠습니다.** 개별 상품 조건은 현재 미확인입니다.

확인 시간: 예상 1~2분 / 실제 약 15초, 2026-11-16 21:29 KST 완료.
