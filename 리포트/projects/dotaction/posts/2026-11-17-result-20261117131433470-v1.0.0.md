## 작업 결과

구현·저장·Godot 실제 렌더링 완료. 게임 배포 빌드는 수행하지 않았습니다.

## 변경 내용

### 적용 내용

기존 로고 원본을 보존하고 AtlasTexture로 방패와 제목을 분리했습니다. 방패 페이드인 후 64px 상승, 배경 조명과 숲·불씨 공개, 제목과 안내 순차 표시를 추가했습니다. 2초 자동 마을 진입을 제거했습니다. 첫 입력은 연출 공개, 이후 입력은 마을 진입입니다. 약한 연출은 위치 이동·불씨·깜박임을 생략합니다. 지침 변경 없음: 기존 규칙을 적용했습니다.

## 검증

Godot 4.7.2/OpenGL/GTX970에서 640×360 실제 렌더 151프레임 저장. SPLASH_RENDER_OK mode=splash age=6.0 errors=[] 확인. 0.72초 방패 단독 중앙 화면과 4.4초 최종 화면을 직접 확인했습니다. 자동 테스트 미실행. 시작 입력 동작은 코드 확인이며 실제 입력 검증은 미실행입니다. 환경의 user:// 로그·캐시 쓰기 오류와 종료 시 기존 텍스처 RID 경고가 있었습니다.
