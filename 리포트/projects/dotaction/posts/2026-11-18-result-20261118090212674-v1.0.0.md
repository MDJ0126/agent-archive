## 변경 내용

### 적용 내용

프레임 이동이 자세 설정을 덮어써 클립별 PNG가 모두 같았습니다. frame_set을 자세 설정보다 먼저 호출하도록 수정하고 Blender 원본·28프레임·정규화 시트·Godot 비교 자료를 다시 만들었습니다. MP4를 추가했습니다. 검증된 교훈은 제작 문서에 통합했으며 전역 지침은 변경하지 않았습니다.

## 검증

수정 전 클립별 서로 다른 PNG: 대기1·걷기1·공격1. 수정 후 대기5/8·걷기7/12·공격8/8. 픽셀 대칭/미세 이동으로 중복 프레임이 있습니다. 실제 Godot 원정 렌더러에서 양쪽 외형 144장을 재촬영하고 자세 변화를 시각 확인했습니다. 데이터 오류 없음. 웹 빌드 완료. 종료 GPU 자원 정리 경고는 기존과 동일합니다.
