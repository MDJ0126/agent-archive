## 변경 내용

### 적용 내용

**Main Camera → Combat Pixel Style**에서 조절하시면 됩니다.

- **Outline Width**: `1`이 최소입니다. 현재 720p에서는 화면상 2px, 1080p에서는 3px입니다.
- **Outline Depth Threshold**: `0.08 → 0.15~0.2`로 올리면 내부의 잔선이 줄어듭니다. 두께 자체를 줄이는 값은 아닙니다.

**진하기는 현재 Inspector에 노출하지 않고 셰이더에 고정해 둔 상태입니다.** CombatFinalPixel.shader (당시 로컬 자료; 공개 첨부 미확인)의 외곽선 분기에 있는 다음 값입니다.

```hlsl
color = float3(.0075, .0075, .016);
```

이미 Width가 `1`이라면, 더 얇게 하려면 현재 양쪽 경계를 잡는 판정을 한쪽으로 바꿔야 합니다. 진하기도 팔레트 적용을 고려해 조절값을 노출하는 쪽이 맞습니다.
