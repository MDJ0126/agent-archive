## 변경 내용

### 적용 내용

트레이는 16px 중심, 작업 표시줄은 32px 중심으로 조정했습니다. 브라우저 파비콘과 같은 알림 읽음 전환을 WebView2로 전달합니다. 디자인 수정까지 프로젝트 1f0601a5에 푸시했습니다.

## 검증

숨긴 WebView2에서 실제 알림이 트레이 아이콘과 작업 표시줄 배지 상태를 켜고 해제하는 경로를 확인했습니다. 헤드리스 브라우저에서 알림 화면 진입 시 원래 파비콘을 복구하고 읽음 메시지를 전달하는 것을 확인했습니다. 수정된 ICO 파일로 다시 검증했습니다. 첨부 이미지는 제작 아이콘의 확대 비교입니다.

## 남은 사항

최신 아이콘의 사용자 Windows 화면 표시는 후속 적용 확인 범위이며 공개 보고서 배포는 미확인입니다.
