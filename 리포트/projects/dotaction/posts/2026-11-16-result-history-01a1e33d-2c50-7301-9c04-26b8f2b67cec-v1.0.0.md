## 변경 내용

### 적용 내용

**이 게임에는 ‘Aseprite 같은 도트 에디터 + 제가 관리하는 제작 규칙·자동화 + GitHub 원본 관리’ 조합을 추천합니다.** 스킬 하나로 그림체를 고정하기보다는, **기준 에셋을 만들고 그 원본에서 확장하는 방식**이 안정적입니다.

이미지 생성은 시안 제작에 유용하지만, 여러 번 생성할 때 캐릭터나 스타일의 일관성이 흔들릴 수 있습니다. 따라서 “같은 스타일로 그려줘”라는 프롬프트만으로 최종 게임 에셋을 계속 생산하는 방식에는 한계가 있습니다. [OpenAI 공식 문서](https://developers.openai.com/api/docs/guides/image-generation)

### 1. ‘균일함’의 기준을 먼저 고정해야 합니다

도트 크기뿐 아니라 다음 항목이 같아야 한 게임처럼 보입니다. 아래 수치는 **초기 제안**입니다.

| 항목 | 도트 액션 + 슬롯 + 증강 카드의 시작 규격 |
|---|---|
| 기본 격자 | 배경 타일 16×16, 캐릭터 캔버스 32×32 |
| 공통 심벌 | 슬롯과 카드에 재사용할 16×16 아이콘 |
| 팔레트 | 공통 24~32색, 재질별 명암 단계 고정 |
| 외곽선·광원 | 기본 외곽선 1px, 광원은 왼쪽 위 |
| 캐릭터 비율 | 머리·몸통·무기 크기와 발바닥 기준점 고정 |
| 출력 | 정수 배율 확대, 최근접 보간, 부드러운 경계 금지 |

**32×32 캔버스라고 전부 같은 크기로 그리는 것은 아닙니다.** 캔버스 안에서 캐릭터가 차지하는 높이, 선 두께, 디테일 밀도까지 맞춰야 합니다. 실제 규격은 전투 시점과 화면에서 보이는 캐릭터 크기를 보고 결정하는 것이 좋습니다.

특히 이 게임은 **같은 심벌을 공유하기 좋습니다.** 예를 들어 ‘번개’ 아이콘 원본 하나를 슬롯 심벌, 증강 카드, 전투 상태 표시에서 재사용하면 시각적 연결과 제작 효율을 함께 얻습니다.

### 2. 도구마다 맡길 역할이 다릅니다

| 도구 | 추천 역할 |
|---|---|
| **Aseprite** | 최종 도트 원본, 레이어, 애니메이션 편집 |
| **Pixelorama** | 무료·오픈소스 도트 에디터 대안 |
| **저와 이미지 생성 도구** | 스타일 시안, 기준 에셋 후보, 수정 방향 제안 |
| **저와 스크립트** | 팔레트·크기·기준점 검사, 변형 제작, 일괄 내보내기 |
| **프로젝트 전용 스킬** | 같은 제작 순서와 규칙을 반복 적용 |
| **GitHub** | 원본·팔레트·규칙·스크립트의 변경 이력 관리 |

자동화를 함께 생각하면 Aseprite를 우선 추천합니다. 공식 CLI로 이미지와 스프라이트 시트, JSON 데이터를 내보낼 수 있습니다. 무료로 시작하려면 Pixelorama도 선택지입니다. [Aseprite CLI](https://aseprite.org/docs/cli/), [Pixelorama 공식 저장소](https://github.com/Orama-Interactive/Pixelorama)

GitHub는 **도트를 균일하게 생성하는 도구가 아니라, 승인한 기준과 원본을 유지하는 장소**입니다.

### 3. 저를 이렇게 이용하시면 됩니다

1. **작은 기준 세트를 먼저 만듭니다.**  
   플레이어 1명, 적 1명, 바닥 타일, 슬롯 심벌 3개, 증강 카드 1장을 한 화면에 배치합니다.

2. **그 세트를 보면서 스타일을 확정합니다.**  
   캐릭터만 예쁜지보다, 전투·슬롯·카드가 함께 있을 때 어울리고 잘 읽히는지 판단합니다.

3. **승인한 원본과 규칙을 프로젝트에 저장합니다.**  
   팔레트, 캐릭터 비율, 외곽선, 기준점, 애니메이션 규칙을 문서와 템플릿으로 남깁니다.

4. **새 에셋은 기존 원본을 바탕으로 확장합니다.**  
   색상·장비·장식 변형은 자동화하고, 새 동작이나 실루엣은 직접 검토합니다.

5. **규격은 자동 검사하고, 그림체는 눈으로 확인합니다.**  
   크기·색상·투명도는 기계적으로 확인할 수 있지만, 자연스러운 동작과 같은 화풍인지는 시각 검토가 필요합니다.

스킬은 이 흐름이 잡힌 뒤 만드는 것이 좋습니다. 스킬에 기준 이미지·팔레트·제작 절차·검사 스크립트를 묶을 수 있지만, **스킬 자체가 이미지 모델의 그림체를 학습시키는 것은 아닙니다.** [스킬 공식 안내](https://learn.chatgpt.com/docs/build-skills)
