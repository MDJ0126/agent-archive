## 작업 결과

나무 출력·연결·재배치 저장 완료. 전체 게임 정상 실행은 미확인입니다.

## 변경 내용

### 적용 내용

작은 마가목·넓은 참나무·키 큰 가문비·굽은 버드나무 고목·갈라진 거목을 제작했습니다. 원본은 art/source/town-trees-v1에 보존했습니다. tools/export-town-trees.py가 128×160/피벗64,150에 각기 다른 실제 크기로 출력합니다. town.json의 나무10그루를 건물 그림 외곽40px와 접근 경로2.2타일에서 떨어뜨리고 town_layout.tscn에 동기화했습니다. 그림자와 바람 출력도 공통 피벗을 사용합니다. 기존 고목 원본과 다른 작업의 변경은 보존했습니다. 공통 디자인·전역 지침 변경은 없습니다.

## 검증

새 PNG5개를 tools/normalize-art.mjs로 정규화했습니다. 출력5종을 직접 열어 크기·실루엣 차이를 확인했습니다. Godot4.7.2에서 실제 마을을 로드한 결과 scenery=39, tree_variants=tree_0~tree_4를 확인했습니다. 전체 임포트에서는 기존 game.gd537/540의 draw_focus_marker 누락과 expedition.gd 종속 컴파일 오류가 발생했습니다. 별도 테스트와 회귀 테스트는 실행하지 않았습니다.

## 남은 사항

실제 게임 화면의 배치·체감 확인은 미확인입니다. 기존 전투 스크립트 컴파일 오류는 이번 나무 수정 범위에서 변경하지 않았습니다. 프로젝트 푸시·게임 배포는 수행하지 않았습니다.
