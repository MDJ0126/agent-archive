## 작업 결과

카드 잔류 버그 수정·5개 콜백 검증·ImageGen 시안 제작 완료. 전체5개 실제 마우스 검증은 PC 포커스 이동 허락을 기다려 부분 완료입니다.

## 변경 내용

### 적용 내용

town_hand_card.gd에서 모달 화면 진입 시 카드 패를 숨기도록 수정. 그림 창·제목 띠·하단 설명·기능 문양을 갖춘5장 카드 디자인 제안 제작. art/concepts/ui/town-hand-v2/design-proposal.png와 제작 메모 보관. 게임에 적용하거나 승인된 시안으로 처리하지 않았습니다. 실제 적용 시 기존 캐릭터·몬스터 외형을 사용합니다. 웹 문서에 제안 이미지와 검증 범위를 갱신. 새 전역 교훈 추가 없이 기존 포커스 보호·검증 구분 지침을 적용했습니다.

## 검증

실제 Windows 마우스: 설정·캐릭터 도감의 dy=-22px, angle=0도 확인 및 해당 화면 진입 확인. 캐릭터 도감 위 카드 잔류를 발견. 수정 후 Godot4.7.2 헤드리스 버튼 pressed 콜백5개 확인: settings, collection_codex heroes, collection_codex monsters, collection_formation, battle 모두 pass=true. 모달의 카드 숨김도 pass. 이는 실제 마우스 입력 검증과 구분합니다. ImageGen 기본 도구 시안 생성·육안 확인, 프로젝트에 복사. 문서 빌드 확인.

## 남은 사항

사용자가 다른 앱을 사용하는 화면이 관찰돼 추가 UI 입력을 중단하고 게임 창 포커스 이동 허락을 질문했습니다. 수정 후5개 전체 실제 마우스 조작·남은3개 호버는 미확인. 검증용 게임 창은 허락 대기로 열려 있으며 기존 편집기 창은 보존했습니다. 게임 저장소 커밋·푸시·배포 미실행. 중앙 보고는 별도 게시 확인합니다.
