## 변경 내용

### 적용 내용

기존 파비콘으로 Windows용 다중 해상도 ICO를 만들고 대시보드 창에 전용 앱 ID와 아이콘 리소스를 설정합니다. 프로젝트 a47b88a5 푸시.

## 검증

Windows PowerShell 5.1로 창 DLL 빌드. 현재 대시보드 창을 다시 시작하지 않고 아이콘을 적용하고 Windows 속성을 다시 읽었습니다. 작업 표시줄의 해당 버튼을 찾아 캡처와 실제 아이콘 표시를 확인했습니다.
