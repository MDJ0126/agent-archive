## 작업 결과

원정 장교 이동기 구현·실제 HUD 버튼 신호 실행 확인. 현재 별도 수집형 진입점과 사용자 멈춤 원인은 미확인입니다.

## 변경 내용

### 적용 내용

classes.officer.mobility를 장교 돌진(charge, 거리4.8·지속0.28초·재사용5초·접촉피해1.5배·준비0)으로 분리했습니다. officer_triple 시작 스킬을 유지하고 player_kit의 E 삼연격 분기와 combat_pilot의 이동기 AI 제외 분기를 제거했습니다. docs/design/captains.md를 갱신했습니다. 기존 이동기 계약을 재사용하여 지침 추가 없음.

## 검증

Godot4.7.2 headless에서 campaign.gd 원정 실제 초기화 후 적이 없는 상태의 HUD E 버튼 pressed 신호 실행: 지속0.28초·재사용5초·속도17.142857·실제 이동4.45715칸(0.02초 실행 간격)·종료 확인, 데이터 오류[]. 삼연격 기본 스킬 유지 및 사용 true·예약3타 확인. 이번 확인에서 대상 피해는 확인되지 않았습니다. 별도 테스트·회귀 테스트 미실행. 사용자 Godot 로그에는 보고한 멈춤 오류 없음.

## 남은 사항

현재 boot.tscn은 collection_game.gd를 사용하여 기존 원정 경로와 다릅니다. 해당 별도 진입점 변경은 보존했습니다. 사용자 멈춤 재현·원인과 화면 품질 미확인. 데이터 도감 빌드는 collection_heroes 매핑 누락, 웹 빌드는 collection_grade_path 중복 ID로 실패하여 docs/index.html 갱신 미완료. 게임 커밋·푸시·배포 미실행. 중앙 등록 결과는 별도 publication JSON.
