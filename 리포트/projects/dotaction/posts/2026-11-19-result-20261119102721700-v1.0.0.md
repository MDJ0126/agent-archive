## 작업 결과

구현·문서 빌드·실제 Godot 렌더 확인 완료. 하단 카드5개와 기존 기능 진입 연결을 유지합니다.

## 변경 내용

### 적용 내용

설정·캐릭터 도감·전장 출발·몬스터 도감·공대 편성을 하단 중앙의5장 카드로 배치. 약간 겹치는 각도와 중앙 카드가 높은 부채꼴 구도, 기존 픽셀 프레임·그림·한글 글꼴 적용. 마우스를 올리면22px 상승하고 각도가0도로 펴지며 앞쪽으로 표시. 모션 줄이기는 즉시 전환. 마을명과 골드도 하단으로 배치. town_hand_card.gd 추가. 문서의 현행 설명·실제 화면·매니페스트 갱신. 사용자 확정을 프로젝트 지침에 통합했으며 전역 지침 변경 없음.

## 검증

Godot 4.7.2 실제640×360 렌더: TOWN_HAND cards=5, data_errors=[]. 첫 렌더에서 양끝 설명 잘림 확인 후 위치 보정, 보정 렌더에서5개 카드 제목·설명과 하단 상태 표시 확인. node docs/build.mjs 성공. 별도 테스트·회귀 테스트 미실행.

## 남은 사항

실제 마우스 호버와 각 카드 클릭 후 서비스 진입은 미확인. user 로그·셰이더 캐시 저장 권한 오류와 종료 시 기존 렌더러 자원 경고가 발생했으나 화면 렌더는 완료했습니다. 게임 커밋·푸시·배포는 미실행. 중앙 보고 게시 상태는 별도 기록합니다.
