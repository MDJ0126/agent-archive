## 변경 내용

### 적용 내용

**품질을 높이려면 ‘좋은 캐릭터 원화 → 기준 이미지 고정 → 모션 제작’으로 순서를 바꿔야 합니다.** 제가 했던 도형 조합 방식은 장비 실루엣·인체 비율·명암 표현이 부족했습니다. Aseprite로 출력한 것만으로 디자인 품질이 확보되지는 않았습니다.

조사한 후보 중 관련성이 높은 것은 다음과 같습니다.

| 도구·GitHub | 도움이 되는 부분 | 비용·한계 |
|---|---|---|
| **[Aseprite AI Artist](https://github.com/with-pebbly/aseprite-ai-artist)** | Codex 지원 MCP와 디자인·팔레트·명암·리깅·애니메이션 스킬 제공. 현재 Aseprite 작업에 붙이기 적합 | MIT. 편집 규칙과 참고 자료를 보강하지만, 결과 품질은 직접 검증 필요 |
| **[Sprite Studio / sprite-maker](https://github.com/JohnKinyanjui/sprite-maker)** | 완성한 원화를 기준으로 관절·발 접지를 지정하고 일관된 프레임 생성. PNG 시트·메타데이터 출력 | MIT, Windows 지원. 초기 공개 버전이며 리깅 결과 보정 필요 |
| **[PixelLab](https://www.pixellab.ai/mcp)** | 픽셀 캐릭터의 방향별 이미지·애니메이션·이펙트 생성. 기준 이미지와 팔레트 지정 기능 제공 | 계정·토큰·생성 비용 필요. 공식 MCP는 있으나 현재 연결되지 않음 |
| **[Retro Diffusion](https://retrodiffusion.ai/app/guide/api)** | 기존 도트 원화를 시작 프레임으로 이동·공격·사용자 지정 동작 생성. 이펙트도 지원 | 생성당 과금. 공식 안내상 고급 애니메이션은 **회당 $0.10부터**. [요금](https://retrodiffusion.ai/pricing) |

**제가 권하는 조합은 `현재 imagegen → Aseprite AI Artist → Godot`입니다.** 추가 서비스 결제 없이 시작할 수 있는 경로부터 확인하는 것입니다. 현재 제공된 `imagegen` 도구로 캐릭터 디자인 시안을 만들고, Aseprite에서 실제 게임 크기의 픽셀·팔레트·윤곽을 정리합니다. 모션 생성이 부족하면 PixelLab이나 Retro Diffusion을 추가 비교하면 됩니다.

다음 제작에서는 이렇게 하겠습니다.

1. **전사 정지 포즈부터 개선:** 성숙한 신체 비율, 읽히는 검·방패 실루엣, 금속 명암, 사선 탑뷰를 먼저 잡습니다.
2. **실제 게임 크기로 확인:** 확대 이미지에서만 좋아 보이는 디자인을 피합니다.
3. **달리기·공격 한 종류부터 제작:** 발 미끄러짐, 장비 변형, 자세의 힘을 확인합니다.
4. 그 품질을 기준으로 궁수·몬스터와 나머지 모션을 확장합니다.

**추천 우선순위는 Aseprite AI Artist 조사·도입과 전사 원화 재디자인입니다.** MCP 추가만으로 그림이 좋아진다고 보장하지는 않겠습니다. 이번에는 공식 문서·저장소를 확인했으며, 설치나 유료 생성, 후보 간 실제 품질 비교는 아직 하지 않았습니다.
