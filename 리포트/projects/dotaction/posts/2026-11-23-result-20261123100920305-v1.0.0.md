## 변경 내용

### 적용 내용

트레이 메뉴에 다시 시작을 추가하고 Windows PowerShell -Restart 호출도 같은 종료 및 시작 경로에 연결했습니다. 메뉴 변수와 명령 옵션의 이름 충돌을 수정했습니다. 프로젝트 644de793 푸시.

## 검증

실제 Windows 트레이 PID 29604가 720으로 교체됐고 관리 서버 PID도 2504에서 8552로 교체됐습니다. 대시보드 창이 자동 표시되지 않았고 응답 및 새 트레이 아이콘을 확인했습니다. 대시보드 빌드 3.13초, 관계도 제작 운영 모달의 검토 기준 일치 확인.

## 남은 사항

작업 표시줄의 창 아이콘과 공개 보고서 배포 표시는 미확인입니다.
