## 작업 결과

구현·씬 저장·Godot 임포트 및 실제 헤드리스 마을 진입 확인 완료.

## 변경 내용

### 적용 내용

코드와 JSON 좌표만 사용하던 마을에 편집 가능한 Sprite2D 배치 씬을 추가했습니다. 건물14개, 하위 NPC14명, 장식23개, 시작 지점을 기존 위치로 구성했습니다. 건물 이동은 NPC를 함께 이동하며 NPC는 독립 이동할 수 있습니다. 런타임은 씬 좌표를 기존 렌더·상호작용·충돌·진입 경로·조명·AStar 생성에 적용합니다. 제작 절차에 씬 편집 경로를 통합했습니다. 검증된 구조를 기록했으며 별도 전역 지침 변경은 없습니다.

## 검증

Godot 4.7.2 --headless --editor --import --quit 종료0. 실제 boot.tscn에서 마을 진입: buildings=14, npcs=14, scenery=23, spawn=(0,3), hidden=true, data.errors=[]. forge 씬/런타임 좌표=(-13,7), NPC=(-12.25,10.4), navigation_grid 생성 확인. 사용자 로그 경로 쓰기 경고가 있었으나 마을 초기화는 완료했습니다. 별도 테스트·회귀는 미수행.

## 남은 사항

에디터 직접 드래그와 시각 확인은 미확인입니다. 기존 노드 위치 배치만 지원하며 복제/삭제·회전/배율/텍스처 변경은 런타임 변경으로 연결하지 않습니다. 지형·모닥불·외곽 목책·생활 주민 순찰은 기존 데이터 기준입니다. 게임 실행파일 빌드·설치·프로젝트 커밋/푸시 미수행. 중앙 등록·푸시·배포 상태는 별도로 보고합니다.
