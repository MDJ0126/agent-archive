## 작업 결과

기존 마을과 전투 경로 복원 완료. 실제 루트 씬 실행에서 기존 전투 코드의 아군5·적5 진입을 확인했습니다. GUI 시각·장기 전투는 미확인입니다.

## 변경 내용

### 적용 내용

첫 구현에서 전투 구도 변경을 별도 간이 전투와 마을 생략으로 잘못 해석했습니다. 사용자 정정에 따라 해당 간이 전투 코드를 제거했습니다. collection_game.gd는 기존 campaign.gd의 시작 연출·마을·NPC·전투·장비·정산·귀환을 그대로 호출하는 확장으로 변경했습니다. 공대 편성5인, 마을/전투의 별도 캐릭터·몬스터 도감 버튼과 태생·최고 등급 데이터는 유지했습니다. 기존 companion_system·four_captains의 공격·스킬·투사체·상태·FX·독립성장 경로를5인으로 확장했고5번째 대장 전환 버튼을 추가했습니다. 아군 좌측·적 우측의 전열2/후열3 초기 배치 후 기존 AI와 조작으로 이동·공격합니다. 사방 연속 생성과 담당구역 제한을 해제하고 적5인 편성 전멸 시 다음 스테이지로 진행하며 기존 결과/마을 귀환을 유지합니다. 기존 마을/장비 저장의4인 계약은 보존하고 새 편성만 별도 저장합니다. 몬스터 도감의 integrated 외형도 지원했습니다. 프로젝트 지침과 웹 문서에서 사용자 정정과 현재 구현을 우선 기록했습니다.
