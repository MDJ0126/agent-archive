## 작업 결과

구현·저장·문서 빌드 완료. 파일 목록은 한글 제목순이며 파일명은 보조 표시입니다. 내부 파일 제목·활성 시트·참조도 한글 우선입니다. 컬럼에 한글 의미와 원본 필드명을 함께 표시하고 셀 선택 시 설명을 제공합니다.

## 변경 내용

### 적용 내용

table-schemas.json의 파일 한글 title, 누락 컬럼 번역, 하위 시트 제목, 일부 시간·비율·여부 설명을 보완했습니다. data-browser.mjs의 제목/파일명 표시 순서와 정렬, sheet.js의 내부 한글 제목/원본명 보조 표시·한글 참조·셀 설명, sheet.css의 헤더/보조 글자 스타일을 갱신했습니다. schema-workbook.mjs에서 한글 파일 제목·컬럼명 누락을 거부합니다. docs/design/data-tables.md와 docs/web/README.md를 동기화했습니다. 게임 데이터 값·타입은 변경하지 않았습니다. 기존 지침에 한글 열 이름 유지 규칙이 있어 AGENTS 추가 변경은 하지 않았습니다.
