## 작업 결과

프로젝트 AGENTS.md와 대시보드 관계도 요약에 게임 설명용 캡처 기준을 추가했습니다.

## 변경 내용

### 적용 내용

정지 화면은 부분 이미지, 동작 설명은 실제 GIF, 소리 설명은 실제 소리 영상으로 보여줍니다. 필요한 때 게임 실행과 엔진 캡처를 사용합니다. 차콜 라이트 테마로 갱신된 현행 지침을 맞췄습니다. main 1b7a8b44에 푸시했습니다.

## 검증

AGENTS.md와 생성 모달의 변경 문구를 대조했습니다. 대시보드 19페이지 빌드 통과, 초기 HTML +944B와 gzip +307B, 문서 노드 수 변경 없음. 새 게임 장면 캡처가 필요한 기능 변경은 없었습니다. 직전 라이트 테마 보고서·PNG HTTPS 200 확인. 전역 업데이트 2026-11-22-001 원격 확인.
